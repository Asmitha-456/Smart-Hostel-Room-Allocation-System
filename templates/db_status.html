Troubleshooting Steps to Fix MongoDB Connection:

  1. Check MongoDB Atlas Network Access:
    Go to MongoDB Atlas → Security → Network Access → Click "Add IP Address" → Choose "Allow Access from Anywhere" (0.0.0.0/0) and Save.
  2. Check your .env Configuration:
    Ensure your .env file in the project folder has the valid Atlas connection string: 
    MONGO_URI="mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority"
DB_NAME=smart_hostel
  3. Check Database User & Password:
    Verify under Database Access in Atlas that the user exists and has readWriteAnyDatabase or readWrite privileges.
  4. Once configured, click the "🔄 Test / Reconnect Now" button above to re-verify.
